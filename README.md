# Portfolio — Johan Sarmiento

Portafolio web personal con estética cyber/tecnológica.

## Stack
- Next.js 14
- React 18
- JavaScript
- CSS puro con responsive design

## Importante
Este proyecto está hecho **sin TypeScript y sin Prisma**.

## Ejecutar

```bash
npm install
npm run dev
```

Después abre `http://localhost:3000`.

## Personalizar antes de publicar

En `app/page.js`:
1. Cambia `tu-correo@example.com` por tu correo real.
2. Revisa los enlaces de los proyectos.
3. Si tienes demos publicadas, agrega el botón/enlace de demo en cada proyecto.

## Deploy

Puedes desplegarlo en Vercel conectando este repositorio de GitHub.
